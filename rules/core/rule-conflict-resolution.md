# RULES 冲突处理

如果用户当前要求, implementation plan 或拟议实现与已生效的 RULES, 项目 `AGENTS.md` 或 `CONTEXT.md` 存在直接冲突, 必须暂停执行.

暂停时必须主动告诉用户:

- 冲突的具体规则和要求.
- 继续执行的收益, 代价与风险.
- 遵守规则和接受例外两种选择的影响.

然后询问用户如何选择. 在用户明确选择前:

- 不得继续实现, 修改或提交.
- 不得通过弱化规则, 绕开检查或静默改变需求来规避冲突.
- 只允许读取必要上下文以准确说明冲突.

如果用户明确选择接受例外, 记录该决定及适用范围后再继续. 如果在实现过程中才发现冲突, 保留当前变更, 立即暂停并执行同样的询问流程.
