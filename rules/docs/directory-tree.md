# 文档目录结构

适用于 Markdown 文档中展示项目/目录结构.

1. 使用 ` ```shell ` 代码块 (模拟 `tree` 输出, 终端友好)
2. 采用 `tree` 命令风格的 ASCII 树形文本, 不用 markdown 表格或嵌套列表
3. 在文件或目录行末用 `#` 加中文简短说明其作用
4. **排序**: 模拟 IDE — 同一层级内先目录、后文件, 各自按字母序 (不区分大小写时可按 ASCII)

## `#` 注释对齐

- 同一层级 (siblings) 内, 尽量让 `#` 纵向对齐
- 以「树形前缀 (`├──` 等) + 名称」整行长度为基准
- 若该层级最长行与最短行长度差 > 10 个字符, 不强行对齐, 名称与 `#` 之间固定 2 个空格
  - 「10 个字符」指整行 (前缀 + 名称) 的长度差, 不是文件名 alone
  - 例: `├── lib.rs` (10) 与 `├── main.rs` (12) 差 2 → 对齐; `├── io.rs` (9) 与 `├── very_long_module_name.rs` (28) 差 19 → 不对齐
- 子层级单独判断, 不跨层级对齐

示例 (对齐):

````markdown
```shell
project/
├── src/         # 源代码
│   ├── lib.rs   # 库根模块
│   └── main.rs  # 程序入口
├── tests/       # 集成测试
├── Cargo.toml   # 项目与依赖配置
└── README.md    # 项目说明
```
````

示例 (不对齐, 固定 2 空格):

````markdown
```shell
src/
├── very_long_module_name.rs  # 核心实现
└── io.rs  # 读写抽象
```
````

- 缩进用 `├──` `└──` `│`, 与 `tree` 输出一致
- 路径和文件名保持原文, 不翻译; `#` 后说明用中文
