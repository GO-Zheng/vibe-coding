# 文档目录结构

适用于 Markdown 文档中的项目或目录结构.

- 使用 `shell` 代码块, 采用 `tree` 风格文本, 不用表格或嵌套列表.
- 使用 `├──`, `└──`, `│` 表示层级, 路径和文件名保持原文; 并在行末用 `#` 添加中文说明.
- 同一层级先目录后文件, 各自按字母序排列.
- 同一层级的说明尽量对齐; 名称长度差异较大时不强行对齐.

## 示例

```shell
project/
├── src/        # 源代码
│   ├── lib.rs  # 库根模块
│   └── main.rs # 程序入口
├── tests/      # 集成测试
├── Cargo.toml  # 项目配置
└── README.md   # 项目说明
```
