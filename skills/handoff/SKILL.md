# Handoff

`handoff` 只用于保存当前未完成任务的进度, 写入工作区根目录 `CHAT.md`. 新 session 通过 `@CHAT.md` 引用即可续接.

## 写入规则

- 当前任务已完成时, 清空 `CHAT.md`, 不保留已完成的旧任务.
- 当前任务未完成时, 覆盖写入 `CHAT.md`, 不追加历史内容.
- 只记录当前任务相关的目标, 状态, 关键决策, 已完成步骤, 待完成步骤, 相关文件和下一步.
- 已存在于其他制品 (spec, plan, commit, diff, issue) 的内容只保留路径引用, 不重复复制.
- 只有后续确实需要调用特定 skill 时, 才添加「建议使用的技能」小节.
- 脱敏: 删除 API key, 密码, 个人身份信息等敏感内容.
- 如果用户传入参数, 按参数描述的焦点定制交接摘要.

## 参考格式

```markdown
# 当前任务进度

- 任务 / 状态: ...
- 已完成: ...
- 待完成: ...
- 关键决策: ...
- 相关文件: ...
- 下一步: ...
```
